# BNCOM chart prototype

Interactive mobile stock chart prototype. Prices and history are demonstration data.

- Swipe horizontally to browse history.
- Hold for 350 ms, then drag to inspect a price and date.
- Switch periods with the buttons below the chart.
- The vertical scale updates synchronously with the visible curve.

## Hosting

The prototype is a self-contained `index.html` with no build step or external dependencies. Publish the repository root with GitHub Pages.
